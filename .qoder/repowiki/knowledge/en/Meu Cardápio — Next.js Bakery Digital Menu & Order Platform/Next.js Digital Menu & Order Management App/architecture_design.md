Built on Next.js App Router with file-system routing: `src/app` holds page components (menu, cart, orders, admin, login) and REST API routes under `src/app/api/*` grouped by domain (`auth`, `produtos`, `pedidos`, `usuarios`, `categorias`, `settings`, `upload`). Server-side logic lives in route handlers that import shared utilities from `src/lib` (authentication via cookies + bcrypt, Firebase client auth, Pusher pub/sub, product cache, login rate limiting). Data access is centralized in `src/db`: `schema.ts` defines Drizzle tables (`produtos`, `pedidos`, `itens_pedido`, `configuracoes`, `usuarios`, `tentativas_login`) over a libSQL/Turso client created in `db/index.ts`. Client state uses Zustand with persistence (`cartStore.ts`) mounted at the app root via `layout.tsx`, which also injects Google Fonts and global CSS. Real-time features are split between server (`pusher-server.ts`) and client (`pusher.ts`, `firebase-client.ts`) modules. The `scripts/load-test.ts` provides load-testing tooling outside the build pipeline.
