The repository is a single Next.js 16 App Router workspace (package name `meu-cardapio-front`) whose source lives under `src/` and is consumed through the child `next_app` module. All runtime configuration is centralized at this level: `next.config.ts` declares image optimization for Cloudinary and Unsplash; `drizzle.config.ts` wires the Turso/libSQL dialect with schema at `src/db/schema.ts` and migration output to `./drizzle`; `tsconfig.json` enables strict TypeScript with the `@/*` path alias pointing to the project root; `eslint.config.mjs` and `postcss.config.mjs` provide shared linting and Tailwind CSS processing used across all pages and components. Database migrations and seeding are orchestrated through npm scripts (`db:generate`, `db:push`, `db:migrate`, `db:studio`, `db:seed`, `db:setup`) that run against either a local `dev.db` file or a remote Turso instance driven by `TURSO_DATABASE_URL` / `TURSO_AUTH_TOKEN` environment variables.
