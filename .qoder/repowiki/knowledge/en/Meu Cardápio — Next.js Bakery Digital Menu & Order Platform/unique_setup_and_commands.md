Development: `npm run dev`. Build: `npm run build` then `npm start`. Database lifecycle: `npm run db:generate` → `npm run db:push` (or `db:migrate`) → `npm run db:studio` for the GUI → `npm run db:seed` to populate data → `npm run db:setup` runs push + seed in one step. Requires `TURSO_DATABASE_URL` and optionally `TURSO_AUTH_TOKEN` for remote Turso; otherwise falls back to local `file:dev.db`.
